# Test Plan: Гурман-Інфо (gourmet-info.netlify.app)

**Версія документа:** 1.0 · **Дата:** 2026-10-30 · **Автор:** Oleg Shotyk

## 1. Мета
Перевірити, що односторінковий лендінг «Гурман-Інфо» працює коректно, доступний, адаптивний і що головна цільова дія (відправка форми «Отримати підбір пари») виконується надійно.

## 2. Об'єкт тестування
Статичний сайт на Netlify (HTML + Tailwind CSS + 3 JS-файли: `menu.js`, `bg-video.js`, `lazy-embeds.js`).

| Блок | Що містить | Ризик |
|---|---|---|
| Шапка / меню | 5 якорних посилань, лого, CTA «Підібрати пару», мобільне меню (`data-menu-toggle`) | Середній |
| Hero | H1, 2 CTA, фонове відео (`data-bg-video`) з кнопкою паузи (`data-video-toggle`) | Середній |
| Переваги, Послуги, Як це працює, Про нас | Статичний контент, 3 кнопки «Обрати формат» → `#contact` | Низький |
| Відео | Лениве вбудовування YouTube (`data-youtube`) | Середній |
| Контакти | Форма `pairing-request` (name, email, message, honeypot `bot-field`), карта Google (lazy iframe), віджет погоди | **Високий** |
| Футер | Навігація, послуги, CTA | Низький |

## 3. У межах тестування (In scope)
Функціональні тести навігації та форми, валідація полів, адаптивність (320/375/768/1280 px), cross-browser (Chromium, Firefox, WebKit), базова доступність (axe, клавіатура), базова продуктивність (Lighthouse), SEO-метадані, поведінка 404.

## 4. Поза межами (Out of scope)
Робота сторонніх сервісів (YouTube, Google Maps, forecast7), навантажувальне тестування, пентест, фактична доставка листів із форми на пошту власника.

## 5. Підхід
1. **Ручне тестування** за тест-кейсами (`test-cases.xlsx`), у т.ч. exploratory-сесія.
2. **Автоматизація:** Python + pytest + Playwright, патерн Page Object. Реальні POST-запити на продакшн **не відправляються**: запит форми перехоплюється через `page.route()`.
3. **Нефункціональні перевірки:** Lighthouse, axe.
4. **CI:** GitHub Actions, запуск на кожен push/PR, HTML-звіт як артефакт.

## 6. Середовище

## 7. Критерії
- **Початок:** сайт доступний (HTTP 200), тест-кейси затверджені.
- **Завершення:** 100% High-кейсів виконано, 0 відкритих Critical/High дефектів (або прийнятий ризик), автотести стабільні 3 запуски поспіль.

## 8. Ризики та попередні спостереження
| # | Спостереження (зі статичного аналізу HTML) | Статус |
|---|---|---|
| R1 | `<form>` не має `data-netlify="true"` та `action`; у коментарі в коді сказано, що це Netlify Forms. Netlify виявляє форми за цим атрибутом, тож відправка може не працювати | **Гіпотеза, потрібне ручне підтвердження** |
| R2 | У формі немає контейнера для повідомлень про успіх/помилку (`role="alert"`/`aria-live`) | До перевірки (UX/a11y) |
| R3 | Заявлено «понад 500 видів» сирів і вин, але видимого каталогу на сторінці немає | Питання до вимог |
| R4 | Декоративні `<img>` мають `alt=""` (це коректно), `lang="uk"` встановлено | OK |
| R5 | Вбудовані карта й відео завантажуються ліниво, залежать від сторонніх доменів | Ризик нестабільності тестів |
